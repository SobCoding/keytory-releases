# Keytory 받기

동영상을 보면서 **속도는 그대로 두고 음 높이(키)만** 바꾸는 안드로이드 플레이어입니다.
노래·악기 연습용으로 키 조절, 미세 조정, 속도, 구간 반복, 목소리 줄이기(반주), 작은 화면(PIP), 백그라운드 재생, 키 바꾼 영상·소리 저장을 지원합니다.

## 내려받기

**[Keytory.apk 받기 (항상 최신)](https://github.com/SobCoding/keytory-releases/releases/latest/download/Keytory.apk)**

이전 버전과 바뀐 내용은 [Releases](https://github.com/SobCoding/keytory-releases/releases) 에 있습니다.

## 설치

1. 휴대폰에서 위 링크를 눌러 `Keytory.apk` 를 받습니다.
2. 받은 파일을 누릅니다. 처음이면 "출처를 알 수 없는 앱" 경고가 나오는데, 파일을 연 앱(크롬·파일 앱 등)에서 **이 출처 허용**을 켜고 설치합니다.
3. 안드로이드 8.0 이상에서 동작합니다.

## 업데이트

앱이 켜질 때 새 버전을 확인해서 위쪽에 **"새 버전이 있어요 [받기]"** 를 보여 줍니다.
[받기] → [설치] 를 누르면 됩니다(처음 한 번은 "Keytory 에서 설치 허용" 을 켜야 합니다). 메뉴 → **업데이트 확인** 으로 직접 확인할 수도 있습니다.
